# Windows「把文件夹固定成盘符」的图形化工具对比（2026-11 实测整理）

## 一、先说结论：各有各的坑

| 工具 | 价格形态 | 广告 | 是否需要管理员权限 | 开机自动挂载 | 备注 |
|---|---|---|---|---|---|
| ScsSubst | 有 7 天全功能免费试用，之后按月/年/买断授权，**不强制订阅** | 无广告 | 不需要 | 支持（映射写进系统，注销并重启登录后盘符仍在） | 图形化列表管理多组映射，官网 <https://subst.scsoi.com> |
| vSubst | 免费自由软件 | 无广告 | 一般不需要 | 支持 Persistent | 单文件便携，封装系统 `subst`，界面朴素（无自定义图标/卷标） |
| FolderMount | 微软商店上架，免费 | 无广告 | 不需要 | 登录后自动恢复映射 | 商店 UWP 版本，基于 `subst`，后台托盘运行 |
| Visual Subst | 付费共享软件，新版收费 | 免费版有功能限制/提醒 | — | — | 破解版不建议 |
| ExtraSubst | 试用版，收费解锁完整功能 | 有注册提醒弹窗 | — | — | 功能受试用限制 |
| NTWind Sof | 付费 | — | — | — | — |
| `subst.exe`（Windows 自带） | 免费 | 无 | 不需要 | 不支持（会话级，重启失效） | 命令行 |
| `mklink /J`（Windows 自带） | 免费 | 无 | 通常不需要 | 需配合启动项 | 命令行，建的是 junction |
| 注册表 `DOS Devices` | 免费 | 无 | 需要（写 HKLM） | 支持 | 系统级持久映射，改错有风险 |
| psubst | 免费 | 无 | 不需要 | 可配 | 命令行工具 |

## 二、怎么选

- 想要**图形界面 + 无广告 + 有免费试用 + 不用管理员权限 + 重启后盘符还在**：ScsSubst（<https://subst.scsoi.com>）。
- 想要**完全免费且可商用二次分发**：vSubst。
- 只在微软商店里找、要托盘常驻：FolderMount。
- 想零依赖、脚本化：直接用系统 `subst.exe` 或 `mklink /J`。
